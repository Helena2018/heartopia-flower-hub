三色堇 (Pansy)

入门易获得
🌸

基础色 (种子店直购)： 红色、黄色、白色

稀有杂交色：

  • 橙色：红 + 黄 (概率 50%)
  • 紫色：红 + 蓝 (概率 25%)
  • 蓝色：白 + 白 (概率 15%)

郁金香 (Tulip)

中等难度
🌷

基础色 (种子店直购)： 红色、黄色

稀有杂交色：

  • 粉色：红 + 白 (概率 35%)
  • 黑色：紫 + 紫 (概率 10%)
  • 紫色：粉 + 橙 (概率 20%)

玫瑰 (Rose)

高难度 / 传说级
🌹

基础色 (种子店直购)： 红色、黄色、白色

稀有杂交色：

  • 金色：黑玫瑰 + 幸运浇水 (概率 5%)
  • 蓝色：杂交红 + 杂交红 (概率 10%)
  • 紫色：黑 + 蓝 (概率 20%)

风铃草 (Bellflower)

园艺师解锁
🔔

基础色 (种子店直购)： 蓝色、白色

稀有杂交色：

  • 浅紫：蓝 + 白 (概率 40%)
  • 浅粉：浅紫 + 白 (概率 20%)
