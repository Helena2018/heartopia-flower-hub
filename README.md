## 🌟 Features

- **🧪 Smart Crossbreeding Calculator**: Select any flower type and parent colors to dynamically calculate breed outcomes and exact probabilities.
- **📐 Interactive Layout Guide**: Displays optimal planting grids (Cross Layout & Checkerboard Layout) that sync colors and species in real-time.
- **🌐 20-Language Localization (i18n)**: One-click seamless translation supporting English, Chinese, Japanese, Korean, French, German, Spanish, and more.
- **🎨 Responsive UI/UX**: Beautifully crafted with Tailwind CSS, supporting mobile, tablet, and desktop views perfectly.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6)
- **Styling**: Tailwind CSS (via CDN)
- **i18n System**: Native client-side JSON localization
